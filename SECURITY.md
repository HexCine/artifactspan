# Security

These local tools do not upload inputs or collect telemetry. Names and paths
can still reveal sensitive information in reports; review reports before sharing.
Resource limits reduce accidental misuse but do not form an OS security sandbox.
Keep Python and dependencies patched. Use synthetic examples in public issues.

Before publication, enable GitHub private vulnerability reporting. After it is
enabled, use the repository Security tab for sensitive reports. Until then, do
not publish sensitive reproductions; this prepared source bundle has no private
reporting channel. See README for tool-specific boundaries.
